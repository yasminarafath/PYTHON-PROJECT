# PYTHON-PROJECT
Employee Data Analysis – ABC Company
This project is a comprehensive analysis of employee data from ABC Company, aimed at uncovering insights into workforce structure, salary distribution, and age demographics across different teams and positions. The project is a part of a data science learning module focused on real-world data preprocessing, analysis, and visualization.

🔧 Preprocessing Steps
Dataset: The dataset provided consisted of 458 rows and 9 columns.

Height Column Correction: The height column was replaced with random integer values between 150 and 180 cm using NumPy to ensure realistic and consistent values.

Null Value Check: Verified the dataset for missing values and confirmed integrity.

Data Cleaning: Whitespace was stripped from column names to avoid key errors during processing.

📈 Analysis Tasks and Results
1. Employee Distribution Across Teams
Counted the number of employees per team.

Calculated the percentage distribution of employees across all teams.

📊 Visualization: Bar chart showing employee count per team.

2. Employee Segregation by Position
Categorized employees based on their job roles or designations.

📊 Visualization: Horizontal bar chart representing the number of employees in each position.

3. Predominant Age Group
Analyzed the age column and categorized employees into age groups (e.g., 20–29, 30–39, etc.).

Identified the most common age group among the employees.

📊 Visualization: Histogram or pie chart displaying age group distribution.

4. Highest Salary Expenditure
Aggregated salary data by both team and position.

Identified which team and position contribute the most to the overall salary budget.

📊 Visualization: Grouped bar chart or heatmap.

5. Correlation Between Age and Salary
Investigated the relationship between employee age and salary.

Used correlation coefficient and scatter plot for analysis.

📊 Visualization: Scatter plot with regression line to show correlation trend.

📌 Key Insights
Team Distribution: Some teams are significantly larger, indicating potential departmental focus or imbalance.

Position Structure: A few positions dominate the workforce, revealing organizational hierarchy.

Age Demographics: Most employees fall within a specific age range, hinting at recruitment patterns.

Salary Allocation: Certain teams and roles are high-cost areas, useful for budget planning.

Age-Salary Correlation: A mild positive correlation suggests salary may increase with age/experience, but not strictly.
